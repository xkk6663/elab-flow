# elab-Flow v4.0.0 发布说明

> GitHub Release 正文。tag `v4.0.0` 指向本版本内核提交。
> 详细变更见 [`CHANGELOG.md`](../../CHANGELOG.md) 的 `[V4.0.0]` 与 `[DSH 插件 1.0.0]` 两条。

## 这是什么

**elab-Flow v4.0.0** —— 嵌入式闭环开发驾驶舱。agent 在一个面板里完成「发现 → 编译 → 烧录 → 调试校验 → 串口闭环」，
开发过程对用户全程可视化（阶梯进度、实时日志、RAM/FLASH 占用、多通道波形）。

本版是主仓大版本，同步发布 **DSH 插件 1.0.0**（npm 包 `dsh-elab-cockpit`）。

## 本版要点

### 帧协议补强：位域 / 变长 / 多 ID / 组帧

- 字段支持 `bit_offset` / `bit_length` / `bit_order`（`lsb0` 默认、`msb0` 线性大端位流），
  有符号位域做符号扩展，位域只允许整型。
- 新增 `frame.length_field`（`type: u8|u16`、`offset/endian/mul/add`）与 `frame.id_field` + `variants`
  （按 id 分发字段，未命中进 `unknown_id` 并跳过）。
- 新增 `serialcodec.encode`：字段值 → 字节（枚举 label、逆 `scale/bias`、位写入、
  固定长/变长反算、head/tail/id/length/checksum 自动写）。
- 只读模板库 `templates/frames/*.json`：`telemetry_u16`、`mavlink_v1`、`modbus_rtu`、`dlt645_read`。
- **兼容红线**：旧 profile 输出形状不变，未启用新特性时不出现 `length_field` / `id_field` / `variants` 键。

### Modbus RTU 主站（★ 新能力）

从「看得懂帧」到「能跟设备对话」，协议层补齐工业现场最常见的那条总线：

- 内核新增 `services/elab/modbus.py`（PDU 编解码 + CRC16 + 异常码 + 功能码元数据）与
  `services/elab/modbusmaster.py`（串口事务、寄存器映射、轮询调度）。
- 功能码 01/02/03/04/05/06/0F/10 全支持，单次读、单次写、**批量读写**（FC15/16 一次多寄存器）；
  从站 1..247，0 号只用于广播写。
- **点表**（31 点 / 5 组 / `rev` 乐观锁）：点位带数据类型、字序、缩放与单位，
  轮询按 `fast`/`diag`/`slow`/`bits` 四档分组，一轮 31 点合并成 8 条事务发出。
- 面板与 Agent 只渲染内核的 `MODBUS_META` 自描述（单位、限值、时序、异常码、错误分类），
  不各记一份数字。
- WebUI 新增 `modbus` 工作区；**DSH 插件右栏新增第 5 个页签 `Modbus`**：
  连接条 / 统计行 / 点表 / 单次读写 / DMA 诊断卡 / 事务流水。
- Agent 侧新增门面 `elab_modbus`（meta·status·open·close·read·write·start·stop·transactions·map）。

配套固件例程 `examples/STM32F411_modbus` 演示硬件串口双缓冲的推荐做法：
**循环 DMA + HT/TC（只作搬运提示）+ IDLE + 20ms 静默定界**，发送侧软件乒乓
（`HAL_UART_TxCpltCallback` 链式续传）；`rx_drain()` 三处调用者用 PRIMASK 临界区保护。
教程见 [`docs/tutorials/09-协议上手_Modbus.md`](../tutorials/09-协议上手_Modbus.md)。

### Agent 自学习协议（★ 新能力）

不写一行命令，从陌生字节到直播解码：

1. 串口监视出现陌生字节 → 复制样本 HEX；
2. `elab_frame_learn action=learn` 产出草稿（置信度 / 回放验证 / 等长证据链）；
3. 人复核字段名 → 落盘保存；
4. 解码器下拉选 profile → 直播解码。

配套 `verify` / `auto` / `codegen`，learn 只产草稿不落盘。

### 工具链 provider（数据与执行分离）

- 新增 `services/elab/provider.py`：manifest 校验、版本约束、注册表、`ResolvedToolchain` 解析、
  安装/卸载与内容哈希复核。
- `elab provider list|search|install|remove`、`elab.lock.yaml`、`elab doctor --strict-lock`；
  `market/index.json` 新增 `providers` 数组。
- ESP32-S31-Korvo 工程迁移为 `provider: espressif/idf@>=1 <2`，ESP-IDF v6.1 实机跑通
  编译 → 烧录 → 烧录校验 → 串口心跳闭环。

### DSH 插件 1.0.0：Agent 工具门面化 27 → 15

**破坏性变更**。注册面从 27 个平铺 `elab_*` 工具收敛为 **15 个混合入口**（7 门面 + 8 细粒度）：

| 门面 | action 枚举 |
|---|---|
| `elab_run` | build / triple / loop / step / preview / cancel |
| `elab_serial` | monitor / write / decode / decoded / stats / read / wait |
| `elab_debug` | open / control / inspect / breakpoint / wait / close |
| `elab_frame` | list / get / preview / save / delete / encode / templates / import |
| `elab_frame_learn` | learn / verify / auto / codegen |
| `elab_pkg` | status / search / install / activate / remove / update / verify / adapt |
| `elab_modbus` | meta / status / open / close / read / write / start / stop / transactions / map |

另有 8 个高频细粒度入口：`elab_status` · `elab_guide` · `elab_log` · `elab_serial_read` ·
`elab_serial_wait` · `elab_serial_capture` · `elab_serial_widget` · `elab_debug_inspect`。

- `elab_guide` 升级为 **group → action 两层意图树**，每个入口带同义词、前置条件与调用示例；
  支持 `topic=overview|run|serial|debug|frame|pkg` 只取一组。
- 工具契约上移 domain 层（`src/domain/tools.ts`），执行实现留在 adapters。
- **过渡期**：插件配置 `toolMode: both` 会额外注册 17 个旧名别名（带废弃提示，执行全转发门面，
  零重复实现）。默认 `facade` 不注册，上下文最省。

### 流程清单归位

`STEP_META` / `KERNEL_PLANS` 从 `cockpit/server.py` 挪到 **`services/elab/flow.py`**
（流程清单 = 芯片无关的步骤词汇与三档定义，唯一事实源），驾驶舱只引用不复制。
新增回归测试守卫「server.py 不得再内联流程清单」。

### 收尾健壮性批次

盘点报告 `docs/reports/健壮性盘点_2026-11-05.md` 的 11 条**全部处置**（8 条修复 + 3 条以更轻手段收敛）：

- `GET /api/runs/active` 只读进程内活动登记簿；`list_runs` 只读首尾行；
- SSE 上限 8 → 16；调试壳层 SSE 按需建；断流状态可感知；
- 串口四路合并轮询（每拍 1 个请求带回四路增量）；全部 fetch 加超时；
- run 清理入口 `events.prune_runs(keep, days, dry_run)`；
- 强杀内核不再留孤儿 openocd（Windows Job Object 兜底）。

## 安装

```bash
# DSH 插件（npm）
npm install dsh-elab-cockpit
# 或从源码路径装
dsh plugin --profile web add github:xkk6663/elab-flow#path:/packages/dsh-elab-cockpit

# 内核（从源码运行，无第三方依赖，Python ≥ 3.10）
git clone https://github.com/xkk6663/elab-flow.git
cd elab-flow && ./elab.cmd pkg bootstrap    # Windows 用 elab.cmd
```

上板另需 CMake + Ninja + ARM GCC + OpenOCD。
